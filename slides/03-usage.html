How to Use

1
Create Slide Files
Add HTML files to the 'slides' folder using numbered naming conventions:
slides/01-welcome.html
slides/02-features.html
slides/03-usage.html
2
Open Presentation
Open index.html in your browser. The presentation will automatically discover and load all numbered slide files.
3
Navigate Slides
Use keyboard shortcuts or navigation buttons:
← → Arrow keys: Previous/Next slide
Space: Next slide
Home/End: First/Last slide
F: Toggle fullscreen
4
Independent Viewing
Each slide can be viewed independently by opening its HTML file directly in the browser.
