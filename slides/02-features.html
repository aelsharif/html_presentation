Key Features

⌨️
Keyboard Navigation
Navigate using arrow keys, spacebar, Home/End keys for quick presentation control.
🖱️
Mouse Controls
Click navigation buttons or slide thumbnails for precise slide selection.
📱
Responsive Design
Fully responsive layout that works perfectly on desktop, tablet, and mobile devices.
🎯
Auto Discovery
Automatically discovers slides using numbered file naming conventions (01-title.html).
⛵
Independent Slides
Each slide is a separate HTML file that can be viewed independently or within the presentation.
🖥️
Fullscreen Mode
Press 'F' key or click fullscreen button for immersive presentation experience.
