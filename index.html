How to Use

Creating Presentations:

  1. Create a folder in the 'slides/' directory (e.g., 'slides/my-presentation/')
  2. Add a config.json file with presentation metadata
  3. Add numbered HTML slides (01-intro.html, 02-content.html, etc.)
  4. Refresh the dashboard to see your presentation

Navigation:

  • Click on a presentation card to open it
  • Use arrow keys or navigation buttons in presentation view
  • Press 'F' for fullscreen mode
  • Use the back button to return to dashboard
